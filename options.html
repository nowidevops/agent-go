Advanced settings — local machine bridges (optional)
For users who want the agent to reach beyond the browser tab: voice input through a local Whisper server, OS-level mouse/keyboard/screenshots, and shell commands, each through a small bridge that runs on your machine and answers only on loopback. Download the bridges pack from the Agent Go page (“Local machine bridges”), follow its INSTALL.md, then fill in the fields below. The two powerful options (desktop control, Run commands) are OFF until you switch them on and need the desktop token; every desktop or shell action asks for your approval first. Both URLs must point at this machine (localhost / 127.0.0.1). The desktop token is what keeps other programs on this computer from using the desktop bridge: treat it like a password. What the agent sees through these bridges (screenshots, command output, transcribed speech) is sent to the model you use, like everything else it reads.

Agent behavior and limits

Default is 32768 so large inputs (code review, full scripts/files) fit. Higher uses more VRAM — on a 30B model / 24GB GPU, 32768 is near the ceiling: if Ollama crashes/OOMs or first-token is very slow, lower it (16384 is a good middle, 8192 is safe). Minimum ~4096 (prompt + tool schemas are ~3.3k tokens). Your exact value is always used — nothing is clamped.
0 = no limit; use the Stop button to halt a run.
When a finite step cap runs out mid-task, the run gets up to 2 automatic extensions (half the original cap each, min 10 steps) with a "finish the remaining work, then answer" nudge — instead of being cut off with required work (e.g. tests) skipped. Never applies to trading or M1 runs, or to sub-agents. Turn OFF to keep hard caps.
How many sub-agents (spawn_subagent) run at once. 1 = one at a time (safe default). On a single GPU, inference is always serialized — raising this only pipelines page/tool work, so only go above 1 if you measure a real speedup. Max 4.
How many local folders can be connected at once via 📁 Local files (MCP) (e.g. a project repo + SN_REF + docs). Address files by prefixing the folder name — read_file "Project Files/README.md". Default 6, max 20. Each folder is a separate permission that must be re-granted after a Chrome restart.
